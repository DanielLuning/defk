# Every compile error code defk has released, one per line: the codes in
# Defk.Errors.entries/0 at each release, active and retired, in registry
# order. The file grows at release time, when the release's new codes are
# appended, and is never pruned: a code keeps its name and is never reused,
# and a code whose construct became valid is retired, not removed
# (docs/guides/stability.md). A retired code's line ends in
# `retired <version>`, the version that retired it; the mark is the only
# change a line ever gets, and a code marked retired stays retired. The test
# suite checks that every code here is in the registry, that the marks and
# the registry agree, and that a retired code is never raised; a code added
# since the last release is not here yet. ci/frozen.sh fails a pull request
# that drops a code.
#
